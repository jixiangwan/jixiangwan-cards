## 三、成功機制（七層，照順序）

**① 專業寫作能力先行**
十幾年記者訓練。採訪、結構、下標、在截稿壓力下產出。
**這是最隱形、也最關鍵的一層。** 看她的帳號看不到這層，但沒有這層其他都不成立。

**② 真實創傷當燃料，而且一開始不為讀者寫**
工作與感情重創 → 諮商師建議自由書寫 → 寫給自己 → 讀者是副產品。
**動機的純度本身就是品質的保證。** 為流量寫的東西讀者聞得出來。

**③ 把感悟轉成「可操作的練習」**
第一本書不是散文集，是**27 個練習**。
後來是儀式、是寫作課。
**感想不能賣，練習可以賣。** 這是整條線最關鍵的一次轉換。

**④ 建立一個可辨識的體系**
不是泛泛的靈性，而是有來歷的：
義大利跟奧修第一門徒欣友修靜心、拿到靈性名、印度修脈輪與咒語唱誦、峇里島。
**有師承、有地點、有名字。這是權威基礎。**

**⑤ 持續借用別人的平台**
女人迷、別人的 podcast、文學節、電影導讀、跟導演對談、政府文化局。
**她沒有只待在自己的 IG 長大。每一次都是進到別人既有的受眾裡。**

**⑥ 多形式交叉餵養**
文字 → 書 → podcast → 音樂 → 儀式 → 課程 → 公司。
每一個形式把人帶到下一個。

**⑦ 她是商業清醒的**
女人迷專訪裡她自己講：右腦接訊息，左腦用社會學等知識拆解。
她也明說想寫小說，但知道「小說不一定是現在市場會賣的文體」，
要思考怎麼在個人化的小說裡提煉大眾會共鳴的品質。
**她不是只跟著靈感走。她會算。**

## 五、互動結構的線索

她那篇 18 格長文：**643 讚、72 分享、25 轉發、只有 4 則留言。**

**分享與轉發加起來接近百，留言只有個位數。**

這代表這類內容是**認同型**，不是討論型。
人們看完覺得「這就是在說我」，然後存起來、傳給朋友——但不留言。

→ **寫出讓人覺得被說中的東西，比寫出讓人想辯論的東西有效。**
→ 不要用「你覺得呢？」當收尾去求互動。這類內容不是靠留言長大的。

（註：這是從單一貼文的互動結構推得的判斷，不是內容研究。）

## 六、這對你代表什麼

### 好消息：你的牌比原本估的強很多

**瑜伽老師 = 你已經有第 ④ 層。**
師承、體系、身體實踐、而且**有教學經驗**。
瑜伽的權威基礎比奧修更廣為接受，也更容易開課變現。
高瑞希是 2025 年才開始做儀式課，你在那一塊已經有底。

**空服員 = 一個高瑞希沒有的觀察位置。**
不只是「到處飛」。是在一個密閉空間裡，長時間近距離看過幾萬個人
最疲憊、最沒有防備、最不體面的樣子。
**那是極少數人有的材料。**
同時：情緒勞動、時差、身體被操、服務業的隱形、永遠在移動沒有家。

**業務 = 你懂怎麼把東西賣出去。** 這點很多創作者完全沒有，而且學不會。

**你的體系可以是「身體」。**
高瑞希走的是聲音（唱誦）與儀式。
你走身體——而身體是最容易轉成「可操作練習」（第 ③ 層）、
也最容易變成課的東西。

### 壞消息：必須講的那一條

**她的文字是十幾年記者訓練出來的。那十年你沒有。**

這是真正的差距，而且不是定位能補的。定位決定你寫什麼，
不決定你寫得好不好。

但這可以練，而且你有工具。差別在於：
**她起跑時文字已經是專業級，你要邊跑邊練。**
所以你的前五十篇會比她的前五十篇醜。這很正常，要先知道。

## 七、新的定位方向（取代舊的 POSITIONING.md）

> **身體、移動、與人的疲憊。**
> 一個教過瑜伽、也在三萬英呎上服務過幾萬人的人，
> 寫身體怎麼記住我們不肯承認的事。

**為什麼這個站得住：**
- 身心靈市場巨大且在長，但**絕大多數內容是「心」與「靈」，很少人從「身」切入**
- 你有真實的身體專業（瑜伽）與真實的身體消耗（空服）
- 「身體記得」這個主題，同時能接住療癒受眾與一般讀者
- 而且它天然可以變成練習、變成課——第 ③ 層的路是通的

**可能的支柱：**
1. 身體記得的事（情緒如何存在身體裡／瑜伽教室裡看到的）
2. 三萬英呎的人間（服務業看到的人性，變造處理）
3. 移動與無根（時差、沒有家、一直在走）
4. 讀到的東西 × 活過的事
5. 占星與象徵（最少的一根，且必須落地）

## 九、她的筆法（2026-10-12 補，依據兩篇全文）

來源：部落格〈妳也是冒牌者症候群嗎？〉（專欄）、〈我喜歡約炮，因為我喜歡謊言〉（第一人稱小說）。
**IG 圖卡與文案一篇都沒有拿到**——IG 擋爬蟲，用本人 token 也讀不到別人的帳號。
下面是從兩種文體裡都出現的共同動作，不是從 IG 推測的。

### 招式一：不解釋的判決句，單句成段

> 識破每一個謊言，是我的性高潮。
> 男人擅長撒謊，女人習慣敷衍。
> 我是他們指縫間的溫柔鄉。
> 習慣會被養成，思考亦然。
> 冒牌者症候群，就是沒有自信罷了。

不抒情、不感嘆、不收尾。丟一個斷語，然後立刻回去講故事。
**讀者被定在那裡，她已經翻頁了。**

### 招式二：講到一半轉過來跟讀者吵架

> 你問我為什麼這麼偏激？喜歡謊言有什麼意思？
> 那我得反問你了，你不覺得世界上所有以真誠包裝的謊言，讀起來總是充滿幽默感嗎？

### 招式三：專欄體的佈局（記者訓練）

朋友的故事 → 給那個感覺一個名字 → 研究／名人背書 → 陌生人的故事
→ 一句尖的引言當轉折 → 回到「你」，給一個可操作的理解

### 季向晚跟她差在哪

**她會跳出來，季向晚不會。** 季向晚的寫法是一直待在場景裡，
從頭到尾描述當下發生什麼、自己感覺到什麼，很少跳出來下斷語。

這不是缺點，是不同的寫法。但「像高瑞希」指的就是這個。

### 還缺的

**她的 IG 貼文截圖（圖卡＋文案）三到五篇。** 只有本人拿得到。
在那之前，任何「她的圖卡怎麼寫」的說法都是用散文推測的，不可靠。

## 十、她怎麼長大的（2026-10-12 補）

來源：newsveg 專訪（2023）。這份比先前的年表有用，因為它講的是**機制**，不是履歷。

### 關鍵的一句

> 粉專上一篇篇貼文，才一剛發佈，**就多達千次轉發**，筆鋒精準犀利，文風卻異常讓人感到療癒。

**她靠轉發長大，不是靠讚。** 而人只轉發「講中別人」的東西。

### 她真實的標題（專訪引用的四個）

```
把自己變更好，就「值得被好男人愛」？你會不會想太美了？
表達憤怒，不是求別人理解
怕別人評論你的穿搭，你有「美麗羞恥症」嗎？
三分鐘熱度，不過是你太急。
```

**四篇沒有一篇在講她自己的故事。**

專訪的原話：「一個個吸睛的標題丟出生活中常會有的思想框架，**挑戰著人們規矩的思考邏輯**。」

公式：**撿起一個大家都有的想法 → 戳破它。主詞是「你」，不是「我」。**

### 敘事型 vs 觀點型

| | 觀點型（她的爆文） | 敘事型（季向晚現在全部） |
|---|---|---|
| 主詞 | **你** | 我 |
| 內容 | 挑戰一個你相信的事 | 我身上發生的事 |
| 讀者 | 轉發給朋友 | 自己收藏 |
| 功能 | **帶新人進來** | **把人留下來** |

兩種都需要。現在的十二篇全是敘事型，**缺的是會被轉發的那一半。**

同一個材料可以翻面：

```
敘事型　我五歲那年阿祖走了，那之後我每天都在哭⋯⋯
觀點型　「哭多了就會好」是一句很溫柔的話。
        它的意思是：把感覺關掉，問題就解決了。
```

（第二種 THREADS.md 第 3 句本來就有，只是沒發展成貼文。）

### 還拿不到的

她的 IG 貼文逐字稿。測過四條路全部失敗：

```
抓 instagram.com / threads.net        登入牆，回空白
graph.instagram.com business_discovery  Tried accessing nonexisting field
graph.instagram.com ig_hashtag_search   Object does not exist
graph.facebook.com                      沒有掛粉專，沒有 app id
```

第一個錯誤是關鍵：**「欄位不存在」，不是「權限不足」。**
讀別人帳號的功能整個不在 Instagram Login 這條路上，勾再多權限也沒用。
它只活在 Facebook Login 那邊，而那邊**一定要掛 FB 粉絲專頁**。
2026-10-12 嘗試連結粉專時，Meta 自己的流程回「很抱歉，發生錯誤」，至今未通。

→ 哪天粉專連上了，再跑完整的貼文數據分析。
