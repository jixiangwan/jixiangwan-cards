# 數據分析協議

> 原則：**新帳號不跟業界平均比，只跟自己的上一篇比。**
> 這份文件裡沒有任何「業界標準是 X%」的數字，因為那種數字來源雜、口徑不一、而且對一個 0 追蹤的帳號沒有判斷力。
> 下面的門檻全部是相對門檻（跟你自己前幾篇比），標示〔判準〕的是我的判斷，不是查到的數據。

---

## 一、每篇發文後要記的七個數字

IG 專業帳號的「成效」面板都有。發文滿 **72 小時** 後記一次（長文圖卡的擴散比短影音慢，24 小時太早）。

| 欄位 | 在哪看 | 為什麼要這個 |
|---|---|---|
| 觸及 | 成效 → 觸及的帳號 | 分母。沒有它底下所有比率都沒意義 |
| 非粉絲佔比 | 觸及 → 粉絲／非粉絲 | **這是唯一能告訴你「演算法有沒有在幫你推」的數字** |
| 儲存 | 成效 → 互動 | 識別型內容的第一指標。有人收藏＝「這段講的是我，我要再看」 |
| 分享 | 成效 → 互動 | 第二指標。分享＝「這段講的是我，我要我朋友知道」 |
| 留言數 | 貼文下方 | 數量不重要，**內容才重要**（見第三節） |
| 追蹤轉換 | 成效 → 由這則貼文帶來的追蹤 | 這篇有沒有把路人變成讀者 |
| 輪播留存 | 成效 → 滑動次數／逐格觸及 | **看完率。第 1 格 → 最後一格掉多少** |

### 讚數不記
讚是看完一秒就能給的反應，對「要不要訂閱」幾乎沒有預測力。儲存、分享、DM 才是。前期不要盯讚。

## 二、三條決策規則

〔判準〕以下是行動門檻，不是好壞評分。

**規則一：看留存，決定要不要改結構。**
如果最後一格的觸及比第一格掉超過一半 → 不是你的結尾不好，是**中間有一格讓人放棄了**。
找出掉最兇的那一格，那一格通常是：純解釋、沒有畫面、或是把前一格的意思再講一次。
→ 處理方式：刪掉，不是改寫。

**規則二：看非粉絲佔比，決定要不要換封面。**
非粉絲佔比低 → 問題在第 1 格。你的第一格要能讓一個完全不認識你的人停下來。
非粉絲佔比高但追蹤轉換低 → 問題在結尾跟 bio。人看完了，但不覺得「我要繼續看這個人」。

**規則三：看儲存／分享比，決定要不要做訂閱。**
- 儲存高、分享低 → 內容很準，但讀者覺得**太私密不好轉發**。這種帳號成長慢，但訂閱轉換率高。
- 分享高、儲存低 → 內容好轉發，但讀者不覺得要留著。成長快，訂閱轉換差。
- 兩個都高 → 這個題目要寫成系列，不要只寫一篇。

## 三、留言要分類，不要只看數量

每篇把留言抄下來分三類。這件事比看數字重要。

| 類別 | 長相 | 意義 |
|---|---|---|
| **A 類：「我也是」** | 「這就是我」「哭了」「怎麼會這麼像」 | 識別成功。這個題目可以再寫 |
| **B 類：「原來可以這樣看」** | 「看完想通一件事」「我會試試看」 | **最有價值。** 這是訂閱制的前身——讀者覺得你能給他新的看法，不只是陪他難過 |
| **C 類：說自己的故事** | 留言比你的貼文還長 | 最高強度的連結。這種人要回，而且要回得像回信 |

〔判準〕**A 類多但 B 類接近 0 → 你只是在讓人難過，沒有讓人往前。** 這是現在最該盯的風險，因為你的定位是療癒不是診斷。出現這個訊號就回去修〈骨架 ⑪〉：結尾要把前面出現過的某個人或某句話重新理解一次。

## 四、授權分兩種，不一樣

| | 讀取（Insights） | 發文（Content Publishing） |
|---|---|---|
| 權限名稱 | `instagram_business_manage_insights` | `instagram_business_content_publish` |
| 能做什麼 | 讀觸及、互動、留言 | 建立並發佈貼文 |
| 不能做什麼 | **不能發文、不能刪文、不能改 bio** | — |
| 風險 | 低。只讀，隨時可撤銷 | 中。發錯會是真的發出去 |
| 建議 | **可以給** | 前十篇先不要 |

讀取權限給我，我能做的事：
- 自動把七個數字抓下來存成表，跑趨勢（哪種開頭的非粉絲佔比高、哪個系列留存好）
- 抓留言做 A／B／C 分類
- 每週給你一份「這週哪一篇的哪一格最該改」

**不給也可以。** 你把成效面板截圖丟給我，我一樣分析，只是要你多動一下手。前十篇用截圖完全夠。
